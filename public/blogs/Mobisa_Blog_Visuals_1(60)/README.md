# Mobisa Blog Visuals

Articles completed: 60
Total images: 275
Format: high-quality WebP (quality 95).

Each article uses the exact slug folder and semantic filenames specified in the production blueprint. Aspect ratios follow the blueprint: 162 images at approximately 16:9 and 113 at approximately 4:3.

## Website installation

Copy the 60 article folders into the Mobisa website `/public/blogs/` directory. For example, `ai-ugc-ads-guide-d2c-brands/cover.webp` becomes `/public/blogs/ai-ugc-ads-guide-d2c-brands/cover.webp`, referenced on the website as `/blogs/ai-ugc-ads-guide-d2c-brands/cover.webp`.

The CSV and JSON manifests list every expected image. Keep the manifests and this README outside the public directory if they are only needed for implementation. The website owns article headlines, analytical graphics, charts, and detailed explanatory text. Add descriptive alt text appropriate to each article.

All visuals were generated with OpenAI image generation and individually visually reviewed. Products, talent, and scenes are illustrative campaign concepts; they do not document real customers, clinical results, or measured campaign performance. Packaging is fictional or unbranded.
